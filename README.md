# 🎮 My Java Game

This is a **work-in-progress Java game** I’m developing.  
The current build is available for testing and feedback. 🚧

## 📥 Download
You can download the latest version from the [Releases section](../../releases).  
Look for the `.jar` file under **Assets**.

## 🎮 How to Run
1. Install [Java 17+](https://adoptium.net/)
2. Download the `.jar` from [Releases](../../releases)
3. Double click to run the game
